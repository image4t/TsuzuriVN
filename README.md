# 綴り — Visual Novel Studio

ブラウザだけでシナリオを編集・再生できる、日本語のビジュアルノベル制作ツール。React / TypeScript / Viteで実装しています。サーバーのデータベースや外部サービスは使用せず、画像と文章を外部に送信しません。

## 起動

Node.js 22.12以上（推奨24）をインストールし、このディレクトリで実行します。

```sh
npm install
npm run dev
```

表示されたURL（既定は http://127.0.0.1:5175 ）をブラウザで開きます。

Windowsでは、初回に`npm install`を実行した後、`start.bat`をダブルクリックして起動できます。ポート入力でEnterを押すと5175を使用し、別の番号を入力するとそのポートで起動します。コマンドから直接指定することもできます。

```bat
.\start.bat 5180
```

通常の起動コマンドでもポートを変更できます。

```sh
npm run dev -- --port 5180
```

指定ポートが使用中の場合はエラーで終了します。別のポートへ自動変更しません。停止はCtrl+Cです。ポート番号を変えるとブラウザの保存領域も変わるため、既存作品を移す場合は元のURLでJSONを書き出し、新しいURLで読み込んでください。

```sh
npm run build   # 型チェックと本番用ビルド → dist/
npm run preview # ビルドしたアプリの確認
npm test        # データモデルのテスト
```

Microsoft Edgeがインストールされた環境では、開発サーバー起動中に`node tests/browser.mjs`で主要操作を自動検証できます。

`node tests/pagination.mjs`で長文のページ分割、文字の欠落防止、固定サイズ、前後移動、文字送りを検証できます。別ポートで起動した場合は環境変数`VN_TEST_URL`にそのURLを指定してください。

`node tests/library.mjs`で作品一覧、編集・改題・複製・削除、保存と復元、旧データ移行、容量不足時のエラーを検証できます。

`node tests/voices.mjs`で画像の引き継ぎ、WAV・MP3の登録、実際の音声再生、保存と復元を検証できます。MP3テスト素材は`tests/fixtures/tone.mp3`（テスト用に生成した短い440Hzの音）です。

`node tests/bgm.mjs`でBGMのループ再生、複数シーンでの継続、曲変更・停止、ボイスとの同時再生、個別の音量調整と保存を検証できます。

`node tests/bulk.mjs`で行別の話者指定、連続行の結合、5,000行の一括処理、下書き復元、シーン追加と保存失敗時の挙動を検証できます。

`node tests/storage.mjs`で既存の作品データを保持したDB更新、作品ごとの下書き分離、作品削除時の下書き削除を検証できます。

`node tests/colors.mjs`でナレーションの余白、話者別の文字色、一括指定画面の色分け、色設定の保存・複製・復元を検証できます。

`node tests/backgrounds.mjs`で背景の引き継ぎ、差し替え・画像なし、並べ替え、途中からの再生、保存と復元を検証できます。

`node tests/theme.mjs`でテーマ切り替え、ブラウザへの設定保存、編集・一括作成画面の配色、再生画面の文字色維持を検証できます。

`node tests/resources.mjs`で`Project/Testシナリオ/無題の物語.json`を使った仮想スクロール、素材の分離・共有、ZIPの往復、未使用素材の回収を検証します。`node tests/resource-migration.mjs`で旧保存方式からの移行と、容量不足時の元データ保護を検証します。これらはテスト用の別ブラウザ領域を使用し、元ファイルを書き換えません。

## 基本操作

- 再生中に背景画像が変わると、約1秒で前の画像をフェードアウトしながら次の画像をフェードインします。同じ画像の引き継ぎや本文のページ送りでは演出を繰り返しません。画像なしへの切り替えや前のシーンへの移動にも適用します。
- ボイス欄の「フルパスを指定して追加」にWAV／MP3の絶対パスを入力し、「パスから音声を追加」を押すと追加できます。複数の場合は1行につき1ファイルで、入力順に登録します。Windowsの「パスのコピー」で付く二重引用符も受け付けます。ローカルサーバー（起動バッチ、`npm run dev`、`npm run preview`）の実行環境から読めるパスを指定してください。静的ホスティングではファイル選択を利用してください。素材データを保存するため、追加後の再生・書き出しは元ファイルに依存しません。
- 再生画面の右下にはボイス再生アイコンを常時表示します。押すと現在のシーンのボイスを最初から再生します。ボイス未設定のシーンや終了画面でも位置と表示は変わらず、無効表示になります。
- 再生メニューの「全画面」でブラウザのバーを隠し、16:9を保って画面に収まる最大サイズへ拡大します。「全画面解除」で通常表示に戻ります。Escapeはメニューが開いていればメニューを閉じ、閉じていれば全画面解除、通常表示では編集画面へ戻ります。「再生終了」は全画面も解除します。本文のページ分割は拡大前後で変わりません。
- 通常の再生画面は話者・本文と控えめな送り表示だけを表示します。右クリック・Mキー・右下の「…」で再生メニューを開くと、作品名・シーン番号・ページ数、前後移動・音量・ボイス再生・全画面・終了を確認・操作できます。メニューは閉じるボタン・外側のクリック・Escapeで閉じます。メニュー操作中は本文が余計に進みません。通常時はクリック・Enter・Space・右矢印で進行、左矢印で戻ります。
- トップ画面・編集画面のヘッダーにある「ダーク／ライト」でUIテーマを切り替えます。選択はブラウザに保存され、再読み込み後も維持します。初期設定はライトです。再生画面やシナリオに設定した話者の文字色は変更しません。
- 本文欄の「コピー」で、選択中のシーンの本文全体を改行も含めてクリップボードにコピーできます。ブラウザがコピーを許可しない場合は、その場にエラーを表示します。
- シーン一覧の「話者」でナレーションや特定の話者を選択し、「ボイス」で未設定・設定済みを絞り込めます。「背景・BGMの条件」を開くと、素材の有無や引き継ぎ・変更・停止でも絞り込めます。各条件は同時に適用され、該当件数と全件数を表示します。「条件をクリア」で全件表示に戻ります。
- フィルタは一覧表示だけに適用され、再生・保存はシナリオ全体が対象です。シーン番号は元の順序のままです。絞り込みで編集中のシーンが非表示になっても編集は継続でき、上下ボタンは元の順序で1つ移動します。
- トップ画面に保存済みシナリオを更新日時順で表示します。各作品の「編集する」から作業を再開できます。
- 一覧の鉛筆ボタンでタイトル変更、複製ボタンで画像と本文を含む独立したコピーを作成、削除ボタンで作品を削除できます。削除前に確認します。
- 編集画面の「シナリオ一覧」でトップ画面へ戻ります。移動前に直前の変更を保存します。
- シーン一覧の「シーンを追加」で作成し、選択したシーンの話者名・本文・画像を編集します。画像のみ、本文のみのシーンも作成できます。
- シーン追加時は末尾に追加し、直前のシーンの背景画像を引き継ぎます。最初のシーンは画像なしです。引き継いだ画像は自由に差し替え・削除できます。TXTから追加するシーンも直前の画像を引き継ぎます。
- 背景画像は「前の背景画像を引き継ぐ」「このシーンで画像を変更」「このシーンから画像なし」を選べます。引き継ぎは画像のコピーではなく再生順から解決するため、前の画像を変更した場合やシーンを並べ替えた場合も即時に反映します。画像なしにした以降は黒背景になり、別のシーンで画像を設定すると再開します。
- 新しく追加するシーン・TXT・一括作成のシーンは背景の引き継ぎが既定です。ファイル選択やドロップで画像を登録すると、そのシーンの画像指定に切り替わります。以前のデータで背景の設定モードが未指定の場合も、画像なしのシーンは引き継ぎとして読み込みます。明示的に「画像なし」を選んだシーンはその設定を保持します。既存のシーンもラジオボタンで引き継ぎへ変更できます。
- シーン編集の「ボイス」でWAV・MP3ファイルを複数追加できます。上から順に再生し、上下ボタンで順番変更、スピーカーボタンで試聴、ごみ箱ボタンで削除できます。音声は1ファイル25MBまでです。新しいシーンには前のボイスを引き継ぎません。シーン複製ではボイスも複製します。
- 再生画面ではシーンに入ったときにボイスを先頭から順次再生します。同じシーンのページ送りでは継続し、シーン移動・終了・編集画面へ戻る際は停止します。前のシーンへ戻った場合も先頭から再生します。「ボイスを再生」で再度再生できます。ブラウザが自動再生を制限した場合は「音声を再生」ボタンを押してください。
- シーン編集の「BGM」でWAV・MP3を設定できます。既定は「前のBGMを引き継ぐ」で、同じ曲はページやシーンをまたいでも最初に戻らずループ再生します。「曲を設定・変更」で曲を変更、「このシーンから停止」で後続シーンも無音にします。曲を設定した場面を並べ替えると、以降の引き継ぎ先も再計算されます。
- 途中のシーンから再生する場合も、前のシーンの設定をたどって適切なBGMを再生します。曲変更・停止した区間へ戻る場合は、その区間の曲を先頭から再生します。作品終了・編集画面へ戻る際はBGMも停止します。自動再生が制限された場合は「BGMを再生」で再試行できます。
- 編集画面のシナリオ設定、または再生画面の「音量」でボイスとBGMを個別に0〜100%で調整できます。0%で消音になります。調整しても音声を再スタートせず、現在の再生に反映します。音量設定は作品ごとに自動保存・JSON書き出しされます。
- シナリオ設定の「話者ごとの文字色」でナレーションと各話者の文字色を変更できます。カラーピッカーまたは`#RRGGBB`の6桁コードで指定し、同じ話者の全シーン・再生プレビューに反映します。未使用の話者も追加でき、一括作成の話者候補に表示します。色設定は作品ごとに保存・複製・JSON書き出しされます。
- 一括作成画面の「話者の文字色を設定」でも変更できます。行の背景とシーンカードを設定色で薄く色分けし、帯・丸印は設定色そのものを表示します。本文と話者名は濃い色を保ち、色に加えて名前でも区別できます。選択中の行は緑の枠で示します。
- シーン一覧はドラッグ＆ドロップ、または上下ボタンで並べ替えできます。編集見出しのボタンで複製・削除できます。
- 画像は選択またはドロップで登録。PNG / JPEG / WebP / GIF / AVIFに対応し、1枚25MBまで。一括追加では画像ごとに新しいシーンを追加します。
- UTF-8 TXTは空行ごとに分割して末尾へ追加します。読込後に各シーンを編集できます。
- 掛け合いをまとめて作る場合は、シーン一覧下部の「文章からまとめて作成」を使います。原稿の貼り付け・UTF-8 TXT取り込み → 行ごとの話者指定 → プレビュー確認 → シーン追加の順に操作します。
- 既存の話者は候補に表示します。新しい登場人物は「純一、詞」のように読点・カンマでまとめて登録できます。「」などで始まらない行は任意でナレーションを自動指定します。セリフの話者は推測せず未指定にするため、行の選択欄で指定してください。
- 同じ話者が連続する行だけを1シーンにまとめます。ナレーションも同様です。結合した本文の改行・字下げを保持し、同じシーン内の空行も保持します。空行自体には話者を割り当てません。
- 複数行をチェックして話者ボタンで一括指定できます。Shift＋チェックで範囲選択、検索や未指定・セリフの絞り込み、絞り込み全行の選択にも対応します。「次の未指定へ」と割当後の自動移動で掛け合いを順に処理できます。Alt+1はナレーション、Alt+2〜9は表示される話者への割り当てです。直近20回の割り当てを元に戻せます。
- 行一覧は100行ずつ表示し、シーン構成は別欄で確認できます。全行の話者を指定してから、末尾または選択中のシーン直後へ追加します。既存シーンは保持し、新しいシーンは挿入直前の背景画像とBGMを引き継ぎます。ボイスは個別に設定してください。
- 一括作成の原稿・行ごとの指定は作品別に下書き保存され、画面を閉じたり再読み込みしたりしても再開できます。原稿へ戻って再解析した場合、同じ位置・同じ本文の行の指定を保持します。下書きはブラウザ内の保存で、シナリオJSONには含めません。作品の複製では変換済みシーンを複製します。
- 「再生する」で最初から、「このシーンから再生」で選択場面から再生します。再生は分岐せず、末尾で終了画面を表示します。
- 再生中はクリック・Enter・Space・右矢印で次へ、左矢印で戻る、Escapeで編集画面へ。画面内のボタンでも操作できます。再生画面は1280×720、テキスト枠は1120×240、本文は22px・行間36pxの固定値です。長文は話者あり4行・ナレーション5行に収まるページに自動分割し、クリックで同じシーン内の次ページを表示します。最終ページの次は次のシーンに進みます。「戻る」は前ページへ、シーン先頭では前シーンの最終ページへ戻ります。小さい画面ではゲーム画面全体を同じ比率で縮小します。
- 文字送り演出はシナリオ設定で有効化できます。送り中の進行操作は全文を表示し、次の操作で場面が進みます。
- ナレーションでは話者名の空欄を作らず、本文を枠の上から表示します。ウィンドウサイズは変更せず、本文は5行まで表示します。話者名があるシーンは4行まで表示します。
- 保存・移動には「ZIP保存」を推奨します。小さな`scenario.json`と画像・音声の原本をまとめた`.vn.zip`を作成します。編集画面の「ZIP読込」またはトップ画面の「ZIPを読み込む」で別作品として復元できます。素材の品質は変更しません。
- 「JSON書き出し」は従来互換の素材埋め込みJSONです。「読み込む」で既存JSONも使用できます。互換JSONはBase64により大きくなるため、素材が多い作品にはZIP保存を使ってください。
- 「新規シナリオ」は新しい作品を追加して編集画面を開きます。既存の作品は保持します。

## 保存について

変更後約350msで作品ごとにIndexedDBへ自動保存します。同じブラウザ・同じURLで再度開くとトップ画面の一覧から編集を再開できます。旧バージョンの作業データは一覧へ一度だけ自動移行します。保存完了前にページを閉じる場合はブラウザの警告を表示します。プライベートモード、サイトデータ削除、ブラウザによるストレージ整理では失われる可能性があるためJSONでもバックアップしてください。ポート番号やホスト名を変えると別の保存領域になります。

一括作成の確定時は、シーン追加と下書きの削除を同一のIndexedDBトランザクションで保存します。保存に失敗した場合は既存シーンを変更せず、原稿と話者指定を残して再試行できます。

ブラウザ内ではシーン本文・素材参照と、素材のバイナリBlobを別のIndexedDBストアに保存します。素材は内容のSHA-256で識別し、同じ画像・音声を使うシーンや複製作品で共有します。通常の文章編集では素材を再保存しません。再生・プレビューにはBlob URLを使い、一覧から作品を開いたときに必要な素材を読み込みます。作品一覧へ戻ると音声などの再生用URLを解放します。

既存のブラウザ内データは初回読み込み時に分離形式へ移行します。本文と素材は同一トランザクションで保存し、失敗した場合は元データを保持して警告を表示します。作品を開いてZIP保存で回収できます。作品削除時と素材変更後には、どの保存作品からも参照されなくなった素材を回収します。複製作品が参照している素材は削除しません。

ZIPでは素材をバイナリファイルとして1点ずつ格納し、シナリオJSONには素材IDだけを記録します。画像・音声は非圧縮で格納し、本文のJSONを圧縮します。同じ素材の重複とBase64による容量増加を避けますが、新しい画像・音声を追加すれば、その原本の容量分は増えます。ZIP読み込みの上限は512MB、素材は1点25MBです。IndexedDBの容量はブラウザ・端末に依存し、自動保存だけでなくZIPでもバックアップしてください。

既存JSONをコマンドで移行する場合（変換スクリプトはNode.js 24以上で実行）：

```sh
node scripts/convert-project.mjs "入力.json" "出力.vn.zip"
```

元JSONは変更せず、出力ファイルが既にある場合は上書きしません。ZIP内の`scenario.json`は参照形式のため、単独ではなくZIP全体をアプリへ読み込んでください。

シーン一覧は可視範囲とその前後だけを描画します。数百・数千シーンがあっても全カードの画像を同時に並べず、選択したシーンは一覧内へ自動スクロールします。上下ボタンとドラッグ＆ドロップによる並べ替えも使用できます。

## 構成

- `src/model.ts`: シーンモデル、JSON検証、TXT分割、画像検証
- `src/storage.ts`: IndexedDB永続化
- `src/App.tsx`: 作品管理・一覧と編集画面の切り替え
- `src/Library.tsx`: シナリオ一覧・タイトル変更・複製・削除
- `src/Editor.tsx`: 編集画面・インポート・エクスポート・自動保存
- `src/Player.tsx`: 再生・文字送り・キー操作
- `src/VoiceEditor.tsx`: ボイスの登録・試聴・順序編集
- `src/useSceneVoices.ts`: シーン単位の音声再生・停止・再試行
- `src/BgmEditor.tsx`: BGMの設定・継続・停止・試聴
- `src/useBgm.ts`: 曲変更時のみ再設定するBGMのループ再生
- `src/AudioVolumes.tsx`: ボイスとBGMの独立した音量調整
- `src/bulk.ts`: 原稿の行分割・話者ごとの結合・シーン変換
- `src/BulkCreator.tsx`: 一括作成・範囲選択・検索・下書き保存
- `src/SpeakerColorSettings.tsx`: シナリオ全体の話者別文字色
- `src/BackgroundEditor.tsx`: 背景の継続・変更・画像なしとプレビュー
- `src/SceneList.tsx`: シーン一覧の絞り込み・仮想スクロール
- `src/sceneFilters.ts`: 話者・属性フィルタと引き継ぎ状態の判定
- `src/assets.ts`: 素材の内容ID・Blob・再生用URL・参照変換
- `src/projectPackage.ts`: ZIPプロジェクトの保存・検証・復元
- `src/speakerStyles.ts`: 一括指定の行・シーンカードの色分け
- `src/style.css`: レスポンシブUI

JSONの形式は`{ version: 1, title, typewriter, scenes, audioSettings, speakerColors }`。各シーンは`{ id, text, speaker, image, imageName, imageMode, voices, bgm }`で、配列順が再生順序です。背景の`imageMode`は`inherit`・`custom`・`none`で、引き継ぎと画像なしは`image: null`、画像指定は`image`にData URLを含めます。旧JSONでは画像ありを`custom`、設定モードのない画像未設定のシーンを`inherit`として扱います。`voices`は`{ id, name, data }`の配列で、`data`にWAV・MP3のData URLを含めます。`bgm`は`{ mode: "inherit" }`、`{ mode: "stop" }`、または`{ mode: "track", track: { id, name, data } }`です。`audioSettings`は0〜1の`voiceVolume`と`bgmVolume`を持ちます。`speakerColors`は話者名から`#RRGGBB`への対応表で、空文字のキーがナレーションの色です。未設定の文字色は`#f3f4f5`です。旧JSONではボイスなし・BGM引き継ぎ・ボイス100%・BGM50%として扱います。読込時にIDを再生成し、重複による編集不具合を防ぎます。シーン分割は`splitText`に分離しており、将来ルールを追加できます。



`node tests/immersive.mjs`で通常時の管理情報非表示、右クリック・Mキー・ボタンによる再生メニュー、長文保持・前後移動・音量・全画面・タブレットの表示を検証できます。

`node tests/audio-paths.mjs`でWAV／MP3のフルパス・複数行入力、保存と復元、エラー時の追加中止、ローカル読み込みの制限、ボイスアイコンの固定表示と再生を検証できます。
